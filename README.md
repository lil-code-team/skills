# 🧠 Developer Skills Collection

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Skills](https://img.shields.io/badge/skills-2-blue)](https://github.com/lil-code-team/skills)

A curated collection of agent skills for modern development workflows. These skills help coding agents generate idiomatic code, apply best practices, and scaffold projects using the latest versions of popular frameworks and libraries.

---

## 📦 Available Skills

| Skill                                      | Description                                                                                                 | Category |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------- | -------- |
| [OpenCollection](/opencollection/SKILL.md) | A modern specification for defining and sharing API collections. Designed for simplicity and collaboration. | API      |
| [OpenCode](/opencode/SKILL.md)             | A comprehensive guide for configuring and using OpenCode agents, tools, permissions, providers, and session workflows. | CLI      |

---

## 🚀 Installation

### Using Skills CLI

```bash
# Install all skills
npx skills add https://github.com/lil-code-team/skills

# Install specific skill
npx skills add https://github.com/lil-code-team/skills --skill=[name]
```
