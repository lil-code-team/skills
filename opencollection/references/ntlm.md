# NTLM Authentication

**Definition**: NTLM authentication

**Attributes**:

- `type` (string, Required): Must be `ntlm`
- `username` (string, Optional): Username for NTLM auth
- `password` (string, Optional): Password for NTLM auth
- `domain` (string, Optional): Domain for NTLM auth

**Example**:

```yaml
type: ntlm
username: myUsername
password: myPassword
domain: myDomain
```
